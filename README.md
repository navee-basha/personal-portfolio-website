🌐 Personal Portfolio Website

A modern, fully responsive personal portfolio website built with HTML, CSS, and JavaScript to showcase my skills, projects, and contact information.
It includes a hamburger menu for mobile, smooth animations, and a downloadable CV section.


---

🚀 Features

🎨 Clean & Modern UI

📱 Fully Responsive Design (Mobile & Desktop)

🧭 Hamburger Navigation Menu

💼 Projects Section with Images

📄 Download CV Button in Hero Section

✉ Contact Section with Social Links

⚡ Smooth Scroll & Hover Effects



---

⚙ Setup Instructions

1. Clone this repository:

git clone https://github.com/navee-basha/portfolio.git


2. Navigate to the project folder:

cd portfolio


3. Open index.html in your browser
Or use Live Server in VS Code for auto-refresh.




---

💡 Customization Guide

Replace text in the Hero section with your name, tagline, and description.

Update the CV file in assets/ and link it in the Download CV button.

Add your project images inside the images/ folder.

Update social media links and contact form details in index.html.



---

🌍 Deployment

You can easily deploy this portfolio using:

GitHub Pages

git add .
git commit -m "Initial commit"
git push origin main

Then go to:
Settings → Pages → Source → main branch → Save

Netlify / Vercel
Drag and drop your project folder or link your GitHub repo.
